# Orin Fenn

Link hub for Orin Fenn. Plain HTML, no build step.

- `index.html` is the whole page
- `img/` holds the artwork

## Publish with GitHub Pages
1. Push these files to a repo.
2. Repo Settings, then Pages, then set Source to "Deploy from a branch" and pick `main` and `/ (root)`.
3. The site goes live at `https://<username>.github.io/<repo>/`.
